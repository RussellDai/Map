# 常州购房地图

基于 **Leaflet + 高德官方瓦片** 的常州市交互地图，底图/数据均无需 Key；
🏙 3D 实景使用高德 JS API 2.0（Key 已配置在 `js/config.js`）。

## 功能
- 🗺️ **高德底图**：与高德地图一致的街道明细，滚轮/双击平滑缩放（3~19级），右下角可切换卫星影像
- ⭕ **生活圈圆圈**
  - 蓝色：遥观卫生院（WGS84 31.7038, 120.0308，已自动纠偏）为圆心，**15 公里**半径
  - 橙色：金坛德国中心（WGS84 31.7377, 119.6517，已自动纠偏）为圆心，**40 公里**半径
  - 圆心图钉**可拖拽微调**，位置自动保存
- 🏘️ **小区标注（购房核心功能）**
  - 放大到街道级别（≥12 级）自动从 OpenStreetMap 加载真实小区（自动 WGS84→GCJ02 纠偏）
  - **鼠标悬停**小区：显示名称、分级、单价、优缺点摘要，以及到每个圆心的**估算车程**（🚗约X分钟，直线×1.2绕行÷分段车速：<5km按35、<15km按45、更远按60 km/h）
  - **点击**小区：填写/修改 单价、总价、优点、缺点、备注，并显示到各圆心的距离、是否在圈内；车程徽章先显示估算值，随后自动用 **OSRM 实际驾车路线**（与🧭路线导航同源，无需 Key）替换并标注「导航」，查询失败静默保留估算值
  - 侧栏清单卡片同样显示到各圆心的直线距离与估算车程
  - 支持「手动标记小区」与搜索框定位；数据保存在浏览器 localStorage，可导出/导入 JSON 备份
- 🏷️ **小区分级**：编辑窗顶部或清单卡片上的三个彩色圆点，一键设为
  **重点关注 🔴 / 备选 🔵 / 排除 ⚫**（再点一次取消）。清单按等级排序
  （重点关注最前、排除最后且淡化显示），侧栏可按等级筛选。
  **分级不改变标记底色**（底色始终表示是否填过信息：灰=未填 / 绿=已填），改用外圈/徽标表达：
  自动加载的圆点为 **红色实线外圈=重点关注 / 蓝色实线外圈=备选 / 灰色虚线外圈+淡化=排除**，
  手动 🏠 标记为右上角同色小徽标，清晰不糊
- 🌐 **街景查看**：清单卡片和编辑窗的「🌐 街景」按钮一键打开 Mapillary 全球街景
  （浏览无需 Key；国内覆盖有限，以主干道为主，详见下方说明）
- 🏙 **3D 实景**：清单卡片「🏙 3D」与编辑窗「🏙 3D实景」按钮打开高德 3D 实景弹窗
  （卫星影像 + 路网 + 3D 楼块，俯仰 62°，可旋转/缩放/倾斜），使用高德 JS API 2.0，
  首次点击时懒加载；Key 与安全密钥配置在 `js/config.js` 的 `amap` 项
- 🎨 **划区域**：点「🎨 划区域」后沿地图点击布点围成自定义购房区域，边界支持
  **自动吸附**——沿**马路/河流**（Overpass 实时加载 OSM 道路与水系几何，WGS84→GCJ02 纠偏，放大到街道级后生效）、
  沿**圆圈边**（本地计算、零延迟）、两点之间即**直线**（可随时用「🧲 吸附」开关关闭）；
  区域可命名/换色/删除，「🔧 调整形状」拖动顶点微调（拖拽同样吸附）、点边中点插点、右键顶点删点；
  小区悬停提示与侧栏卡片会显示其所属区域徽章；数据随本地存储、云同步与导出/导入一并保存
- 🔍 **快速搜索**：输入时即时显示本地已加载小区（0 延迟）；回车联网搜索走
  高德 PlaceSearch(POI)+Geocoder / Photon / Nominatim(多镜像) **三源并行竞速**（谁先到谁先渲染，互为备份；
  高德 PlaceSearch 直接命中小区/村委会/学校等命名 POI，国内中文最强，浏览器拦截高德时自动跳过）
  → 全部无结果时 Overpass 多镜像深搜兜底（全词+词干模糊匹配，「洪庄村委会」也能命中「洪庄村」），
  搜索结果带地址副标题，点击定位、「＋标记」一键加为小区；相同关键词**持久化缓存秒出 + 后台联网刷新纠正**
  （旧结果会被新源自动替换；名称精确命中的结果置顶，排在外省模糊匹配前面；搜不到时状态栏标注哪些源不可用）；
  下拉已有结果时，鼠标移出再移回/悬停聚焦搜索框只恢复显示、不清空（关键词变化才重新过滤，在线结果不会退化成「本地无匹配」）
- 📱 **手机/平板适配**：手机端清单为底部抽屉式（bottom sheet），**同屏至少展示 3 个小区卡片**并可触摸滚动；
  顶栏紧凑化（品牌+搜索同行，功能按钮单行横滑），卡片压缩排版（分级/街景/3D/航拍入口收进 ✏️ 编辑弹窗），
  ▾ 按钮可收起清单让地图最大化；平板（769~1200px）保持左清单右地图布局，顶栏自动换行不裁切、侧栏收窄；
  小屏放大小区/搜索图钉与分级徽标、提高表情图标尺寸（≥13px）避免图形发糊；
  采用 `100dvh` 适配手机浏览器地址栏伸缩，避免清单底部被裁掉

## 使用方法
1. **最简单**：直接双击打开 `index.html`（需联网；Chrome/Edge 均可）
2. 推荐方式（避免个别浏览器对 file:// 的限制）——在 VS Code 中安装 **Live Server** 扩展，右键 `index.html` → Open with Live Server
3. 或用命令行（本机已装 Node）：
   ```
   cd c:\Users\dach\Documents\VSCODE\Map
   npx serve .
   ```

```
index.html        页面结构
css/style.css     样式
js/gcoord.js      WGS84→GCJ02 坐标纠偏
js/config.js      圆心坐标、瓦片地址等配置

js/overpass.js    OpenStreetMap 小区数据加载（多镜像故障转移）

js/amap3d.js      高德 3D 实景弹窗（懒加载 JS API 2.0）

js/sync.js        跨设备云同步（Gitee/GitHub 私有仓库）
js/app.js         地图初始化与交互
```

## 说明与注意
- 小区自动数据来自 OpenStreetMap，覆盖不如高德 POI 全；找不到的楼盘请用「手动标记小区」或搜索框（结果可一键标记）
- **关于街景**：真正的高清街景影像需要服务商授权（高德/百度/腾讯街景均需各自的 API Key）。
  本项目接入 **Mapillary**（Meta 的全球众包街景，浏览无需 Key）：点「🌐 街景」在新窗口打开该位置的实景。
  注意国内影像覆盖有限（主干道为主，小区内部可能没有），无影像时会显示地图，可拖动查找附近路段。
  如你申请到高德 Web 服务 Key，可进一步替换为高德官方街景（覆盖更全）
- 搜索速度：高德 POI / Photon / Nominatim 三源并行（秒级），搜过的词持久化缓存秒出、后台刷新自动纠正；
  全部失败才走 Overpass 深搜（会提示预计耗时）。若状态栏提示某源「不可用」，多为限流（隔几秒重试）或浏览器广告拦截
- Overpass 公共服务器偶尔繁忙（429/503），已做多镜像故障转移/并行竞速，失败时稍后重试即可，不影响其他功能
- 清空数据：浏览器 F12 → Application → Local Storage → 删除键 `cz-house-map-v1`
- **导入格式**：除标准导出文件外，也兼容 `{ "communities": [ {...} ] }` 和直接的小区数组
  `[ {"name":"…","lat":31.7,"lng":119.9} ]`；缺 `id` 会自动生成，坐标无效或字段缺失的条目会被跳过并计数提示。
  若导入后清单仍为空，页面会提示「坐标无效已跳过」，请导出检查对应条目
- **3D 实景黑屏排查**：弹窗内会先显示「⏳ 正在加载…」，8 秒未渲染时显示自查清单。
  常见原因：Key 服务类型不是「Web端(JS API)」、安全密钥与 Key 不配对、
  Key 设了域名白名单但没加当前域名、或用 file:// 直接打开页面（应通过 Live Server 等 http(s) 地址访问）；
  具体报错见浏览器控制台（F12）中以 `AMap JSAPI` / `INVALID_USER_KEY` 等开头的行
- 坐标系统：底图为 GCJ02（高德），OSM 数据均经 gcoord.js 纠偏后叠加，两者对齐；打开街景前会反向纠偏为 WGS84
